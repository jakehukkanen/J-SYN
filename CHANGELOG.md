# Changelog

## v0.2 (`v0.2.0`)
- **Added `Tube Res.` Master FX Module:** Zero-allocation waveguide/tube resonator with pre-allocated delay lines across `Bus A` & `Bus B` (`STK 1..4`), note-snapping `TUNE` knob (`C0..=C6`, default `C1`), loop bandpass filter (`[• FLT]`, `FLT FREQ`, `FLT WDTH`), `FEEDBK` decay, `Pitch LFO` (`MAIN | LFO` sub-tab) tied to global `Dirty` / `Clean` engine quality, and live harmonic comb scope.
- **Hardened Preset Loading:** Bumped patch schema to `v2` storing canonical `EnumParam` variant names alongside unnormalized plain values (`Hz`, `dB`, `%`, integer steps), added automatic legacy `v1` (`v0.1`/`v0.1.1`) migration, deterministic missing-parameter resets, lenient `ModMatrix`/`ModSeq`/`MSEG` deserialization tolerant of unknown/future fields and truncated/extended arrays, BOM stripping, atomic writes, and cross-platform wavetable lookup fallback.
- **Added Pitch Ratio Mode:** Per-oscillator right-click context menu on `PITCH` / `RATIO` to toggle between **`Pitch (Semitones)`** and **`Ratio (FM Harmonic)`** (`0.0000–32.0000 ×`), featuring FM8-style split-zone vertical dragging (left half integer/harmonic ladder `0, 0.25, 0.5, 1..32`; right half fractional `0.10` / `0.01` / `0.001`), a companion **`Hz Offset`** (`±1000 Hz`, biased near `0.1–20 Hz`) linear frequency beat control, and 8 new modulation matrix destinations (`OSC 1–4 RATIO` & `OSC 1–4 HZ`).
